# GCD-Both 分组五折阈值校准报告

## 结论

本轮校准未通过预先冻结的验收门槛，按实验计划停止 seed 43、44 的四组配对训练，继续保留
Baseline 作为正式候选。校准代码能够稳定复现完整流程，但当前证据不支持把 GCD-Both +
全局校准阈值投入下一阶段。

GCD-Both 的五折 OOF 整体 Recall 和 FDR 均优于 Baseline，舰船 Recall 也提高，但舰船 FDR
为 `0.182927`，超过上限 `0.18`；五折独立选择的阈值极差为 `0.075`，超过上限 `0.05`。
因此中位数阈值 `0.425` 仅保留为诊断结果，没有发布为部署配置。

## 多种子阶段

seed 43、44 的 Baseline/GCD-Both 四组 80 epoch 训练未启动。这是计划中的显式停止条件，
不是训练中断。因此三种子 mAP50-95 均值、标准差、正增益 seed 数和逐 seed 校准后
Recall/FDR 均标记为 `not run`，不能据此对 GCD 的跨 seed 稳定性作正面结论。

历史 seed 42 独立 AP 验证仍只作为上一轮事实：Baseline mAP50-95 为 `0.770181`，
GCD-Both 为 `0.774454`，增益 `+0.004273`。本轮失败说明这项 AP 增益尚未同时转化为稳定、
可接受的舰船 FDR。

## 产物与复现状态

- 正式校准命令按预期以退出码 `2` 表示验收失败，同时完整写出 summary、折分、逐折结果、
  OOF report 和 OOF predictions。
- 失败结果没有生成 `calibrated-thresholds.yaml`，也没有生成或修改部署配置。
- 没有训练新权重，没有覆盖 seed 42 结果，没有提交预测、权重、日志、图像 ID、源图名称或
  设备信息。
- Ruff format、Ruff check、完整 pytest 和 coverage 均在最终代码与报告提交前重新执行。

## 推荐

继续使用 Baseline。下一轮若继续研究 GCD，应另立实验验证更贴近失败原因的方案，例如在
阈值选择阶段显式加入舰船 FDR 约束、使用混合回归损失，或加入困难负样本；这些都属于新的
假设，不应在本轮结果上事后修改门槛后宣称通过。
